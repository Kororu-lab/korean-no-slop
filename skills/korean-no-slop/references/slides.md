# 발표 슬라이드

청중이 화면에서 읽어야 할 내용과 발표자가 설명할 내용을 구분한다. 발표용 화면, 배포용 자료, 발표자 노트에 각각 필요한 분량을 적용한다.

## 화면의 문구

제목은 짧은 주제나 핵심 주장으로 쓸 수 있다. 항목은 레이블·구절·수치로 구성할 수 있다. 모든 항목에 주어와 `~입니다`, `~할 수 있습니다`를 붙여 문장으로 늘리지 않는다. 반대로 의미에 필요한 조건과 관계는 생략하지 않는다.

제목 아래 부제, 본문 아래 결론, 카드 아래 설명을 매 장 동일하게 채우지 않는다. 제목과 도표만으로 충분한 장은 그대로 완성한다. 그래프의 단위·기간·범례·출처는 정보로 취급한다.

| 가상 원문 | 화면용 표현 |
| --- | --- |
| 처리 시간이 기존 대비 30% 감소한 것으로 나타났습니다. | 처리 시간 30% 단축 · 기존 대비 |
| 참여자의 48%가 모바일 기기를 사용한 것으로 조사되었습니다. | 모바일 이용 48% |
| 표본 수가 적어 결과를 일반화하기 어렵습니다. | 소표본 · 일반화에 주의 |

배포용 상세 슬라이드나 문장형 제목이 명시된 템플릿이면 그 형식을 유지한다. 짧게 쓰기 위해 주장의 확실성이나 통계적 의미를 바꾸지 않는다.

## 편집과 노트

문장이 길어서 화면을 정리할 때는 설명 일부를 노트에 옮길 수 있다. 사용자가 내용 자체를 삭제하라고 한 경우에는 삭제 범위를 노트에도 적용한다. 위치만 바꾸라는 지시가 있으면 그 지시를 따른다.

삭제한 개념의 문제점, 해당 내용을 다루지 않는다는 안내, 수정 이력을 새 슬라이드나 노트로 추가하지 않는다.

## 검증

실제 렌더링에서 글자 크기, 읽는 순서, 텍스트 밀도, 잘림과 빈 상자를 확인한다. 부제를 지운 뒤 남은 제목과 도표가 자연스럽게 배치되는지 살핀다. 내용 삭제 검토에는 화면 밖의 노트·숨김 텍스트도 포함한다. 새 여백을 다른 문장으로 채우지 않는다.
